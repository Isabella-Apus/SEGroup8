# UC04 用户封禁、解禁与审计设计

本文件沿用 UC06 的独立用例设计结构，仅覆盖 Day 3 组件级设计；对象级图和 E2E 留到 Day 4。

## 接口设计

| 方法 | 路径 | 控制器 | 服务接口/实现 | 数据归属 |
|---|---|---|---|---|
| GET | `/api/admin/users` | `AdminUserController` | `AdminUserService.pageUsers` | `user` |
| PUT | `/api/admin/users/{userId}/ban` | `AdminUserController` | `AdminUserService.banUser` + `AdminAuditLogService.record` | `user`、`admin_audit_log` |
| PUT | `/api/admin/users/{userId}/unban` | `AdminUserController` | `AdminUserService.unbanUser` + `AdminAuditLogService.record` | `user`、`admin_audit_log` |
| POST | `/api/auth/login` | `AuthController` | `AuthService.login` | `user` |
| GET | `/api/admin/audit-logs` | `AdminAuditLogController` | `AdminAuditLogService.pageLogs` | `admin_audit_log` |

## 系统级交互

~~~mermaid
sequenceDiagram
    autonumber
    actor Admin as 管理员
    actor User as 普通用户
    participant Platform as 交易平台
    Admin->>Platform: GET /api/admin/users
    Platform-->>Admin: 返回用户列表
    Admin->>Platform: PUT /api/admin/users/{userId}/ban
    Platform-->>Admin: 用户状态变为 BANNED
    Platform-->>User: 后续登录被拒绝
    Admin->>Platform: PUT /api/admin/users/{userId}/unban
    Platform-->>Admin: 用户状态恢复 NORMAL

    Platform-->>User: 登录成功
    Platform-->>Admin: 写入 BAN_USER / UNBAN_USER 审计记录
~~~

## 组件级交互

~~~mermaid
sequenceDiagram
  actor Admin as 管理员
  actor User as 被治理用户
  participant UAPI as AdminUserController
  participant UserSvc as AdminUserServiceImpl
  participant Users as UserMapper
  participant Audit as AdminAuditLogService
  participant Auth as AuthServiceImpl
  participant JWT as JwtUtils
  participant DB as user/admin_audit_log

  Admin->>UAPI: PUT /api/admin/users/{id}/ban
  UAPI->>UserSvc: banUser(id)
  UserSvc->>Users: 校验当前管理员和目标用户
  Users->>DB: SELECT user
  UserSvc->>Users: update status=BANNED
  Users->>DB: UPDATE user
  UAPI->>Audit: record(BAN_USER, USER, id)
  Audit->>DB: INSERT admin_audit_log
  UAPI-->>Admin: success

  User->>Auth: POST /api/auth/login
  Auth->>Users: 查询账号、密码和状态
  Users->>DB: SELECT user
  alt status=BANNED
    Auth-->>User: 403 登录失败
  else status=NORMAL
    Auth->>JWT: createToken
    JWT-->>Auth: signed JWT
    Auth-->>User: success
  end

  Admin->>UAPI: PUT /api/admin/users/{id}/unban
  UAPI->>UserSvc: unbanUser(id)
  UserSvc->>Users: update status=NORMAL
  Users->>DB: UPDATE user
  UAPI->>Audit: record(UNBAN_USER, USER, id)
  Audit->>DB: INSERT admin_audit_log
  UAPI-->>Admin: success
~~~


管理员治理由 `AdminUserController → AdminUserServiceImpl → UserMapper` 完成，Controller 成功后调用审计服务。登录联动由 `AuthServiceImpl` 读取状态，封禁用户不会取得有效登录结果。

## 组件职责与规则

- `AdminUserController`：提供管理员用户治理路由；封禁/解禁成功后记录审计。
- `AdminUserServiceImpl`：校验当前用户角色、禁止管理员自封禁、修改目标用户状态。
- `AuthServiceImpl`：登录时除密码外校验 `user.status`。
- `AdminAuditLogServiceImpl`：以当前管理员 ID 写入 `admin_audit_log`。
- `AdminAuditLogController`：提供管理员查询入口；其权限校验应在服务层保持一致。
- `user.status` 是账号登录状态来源；`admin_audit_log` 不替代用户状态。
