# UC16-UC20 k6 压测框架与数据重置方案

## 范围

本方案覆盖 PLAN2 成员 D 在 Day2-Day4 的性能准备和首轮单体试压，不包含 Day5 中期演示，也不形成最终性能结论。

| 性能对象 | 脚本 | 用途 |
|---|---|---|
| 商品搜索 | `performance/k6/product-search.k6.js` | 同时请求新品和二手搜索 |
| 新品下单 | `performance/k6/new-order-create.k6.js` | 验证订单创建链路 |
| 二手直接购买 | `performance/k6/secondhand-buy.k6.js` | 验证二手商品状态竞争和订单创建 |
| 拍卖出价 | `performance/k6/secondhand-auction-bid.k6.js` | 验证竞价更新和并发保护 |

## 可重复运行条件

- 基线固定为不可修改的 Git 标签 `monolith-start`。
- 基线栈使用独立端口 `18088/18089/13307`、独立网络和独立 MySQL 卷，不覆盖日常开发栈。
- 首轮统一使用 `2 VUS / 10s`，只验证脚本、接口和数据重置。
- 正式比较至少运行三轮，并固定机器、数据集、VUS、持续时间和 k6 镜像摘要。
- 原始时序 JSON、汇总 JSON、控制台日志和元数据必须同时保留。

## 启动 monolith-start 基线

先在仓库之外检出标签，保证标签本身不被修改：

```powershell
git worktree add --detach ..\SEGroup8-monolith-start monolith-start
$env:FRONTEND_HOST_PORT = "18088"
$env:BACKEND_HOST_PORT = "18089"
$env:MYSQL_HOST_PORT = "13307"
docker compose -p segroup8-monolith-baseline `
  -f ..\SEGroup8-monolith-start\compose.yml `
  -f .\04_tests\performance\monolith-start.compose.override.yml `
  up -d --build
```

## 重置数据

性能数据使用保留 ID，重置脚本只删除并重建这些测试行，不清理普通业务数据：

```powershell
.\04_tests\performance\reset-performance-data.ps1 `
  -ComposeFile ..\SEGroup8-monolith-start\compose.yml `
  -ComposeOverrideFile .\04_tests\performance\monolith-start.compose.override.yml `
  -ProjectName segroup8-monolith-baseline
```

重置后应看到：3 个性能账号、1 个新品、42 个二手商品和 2 个进行中拍卖。两个拍卖分别供两个 VU 使用，性能买家具有专用测试余额。

## 首轮运行

脚本通过 Docker 运行 k6，因此本机不要求单独安装 k6：

```powershell
.\04_tests\performance\run-k6.ps1 -Scenario product-search -ResultPrefix 20260826-monolith-product-search-run1

.\04_tests\performance\run-k6.ps1 -Scenario new-order-create -ResultPrefix 20260826-monolith-new-order-create-run1

.\04_tests\performance\reset-performance-data.ps1 `
  -ComposeFile ..\SEGroup8-monolith-start\compose.yml `
  -ComposeOverrideFile .\04_tests\performance\monolith-start.compose.override.yml `
  -ProjectName segroup8-monolith-baseline
.\04_tests\performance\run-k6.ps1 -Scenario secondhand-buy -ResultPrefix 20260826-monolith-secondhand-buy-run1

.\04_tests\performance\reset-performance-data.ps1 `
  -ComposeFile ..\SEGroup8-monolith-start\compose.yml `
  -ComposeOverrideFile .\04_tests\performance\monolith-start.compose.override.yml `
  -ProjectName segroup8-monolith-baseline
.\04_tests\performance\run-k6.ps1 -Scenario secondhand-auction-bid -ResultPrefix 20260826-monolith-secondhand-auction-bid-run1
```

结果保存在 `04_tests/performance/results/`。实际数值只证明脚本在当前机器上可运行，不代表单体或微服务的最终性能。
