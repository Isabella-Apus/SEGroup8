# 历史测试资产

本目录保存从 `04_tests` 根目录迁出的旧聚合测试材料，避免历史文件与当前自动化入口混放。

- `UC01-UC05/`：早期 API 测试计划与公开接口映射；
- `UC16-UC20/`：Domain D 的旧人工 UI 走查、验收表、演示请求和验证器；
- `UC21-UC25/`：Domain E 的阶段性后端 API/E2E 聚合报告；
- `runtime-reports/`：本地临时报告，仅保留在工作区且由 Git 忽略。

这些文件只用于历史追溯，不代表当前测试状态。当前状态以 `04_tests/UC01/`–`UC25/`、`04_tests/domains/`、最新 GitHub Actions 和 `02_docs/` 中的正式报告为准。
