## 代码评审清单

- [ ] 服务边界按业务能力划分，不把网关或数据库计为业务服务
- [ ] 每张表只有归属服务写入，没有跨 Schema 联表
- [ ] 卖家/用户/管理员身份不能操作他人资源
- [ ] 商品生命周期的每个状态转换均有明确规则
- [ ] 跨服务失败不会造成商品错误上架或人工审核决定丢失
- [ ] Docker 镜像使用固定版本号，进程以非 root 用户运行
- [ ] Kubernetes 包含启动、就绪、存活探针和资源请求/限制
- [ ] 测试失败时 GitHub Actions 作业失败，后续交付不得继续
