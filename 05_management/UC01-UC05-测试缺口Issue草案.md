## Issue 1：补齐 UC01 注册、登录与角色鉴权的 API/E2E 测试

- 标题：`[DAY2][UC01] 补齐注册、登录与角色鉴权的 API/E2E 测试`
- 标签：`use-case`、`test-gap`、`member-a`、`identity-governance`
- 用例：`REQ01 / UC01`
- 服务：`identity-governance-service`
- 执行人：成员 A / `znn`
- 评审人：成员 E / `gjt`
- 计划完成日：`2026-08-26`

### 背景

当前已有 `AuthServiceImplTest` 覆盖密码加密、登录成功、旧密码升级和错误密码，但尚未形成从 HTTP 接口到鉴权结果的完整证据链。需要把 UC01 的注册、登录、无效参数和角色边界落实为可重复执行的 API 测试，并保留后续 E2E 测试入口。

### 工作内容

- 为 `POST /api/auth/register` 增加成功、重复用户名、必填字段/格式错误场景。
- 为 `POST /api/auth/login` 增加成功、密码错误、用户不存在、被禁止用户登录失败场景。
- 为受保护资源增加无 Token、普通用户 Token、管理员 Token 的权限边界测试，至少覆盖 `/api/admin/users`。
- 检查响应中的 `code`、`message`、`data`，不能只断言 HTTP 状态码。
- 将测试编号落实为 `UNIT01-01~03`、`INT01-01~04`、`E2E01-01~04`，并回填追溯矩阵。

### 验收标准

- [ ] 注册成功后用户角色为 `USER`、状态为 `NORMAL`，数据库中的密码不是明文。
- [ ] 登录成功返回可验证的 JWT、角色和用户摘要。
- [ ] 重复注册、错误密码、无效参数均返回明确失败结果，不产生错误数据。
- [ ] USER 访问管理员接口被拒绝，ADMIN 访问成功。
- [ ] 测试可使用单条 Maven 命令执行，结果和日志附在 PR 中。

### 现有基线与证据

- 现有单元测试：`backend/src/test/java/com/segroup8/platform/service/impl/AuthServiceImplTest.java`
- 需求与验收：`01_requirements/UC01-UC05-用例说明.md` 的 `REQ01 / UC01`
- 系统级设计：`02_docs/UC01-注册登录与角色鉴权-设计.md`
