## 代码评审清单

- [ ] UC16-UC20 用例说明完整，每个用例具有系统级、组件级、对象级图
- [ ] 二手商品只能由发布者本人编辑、删除、上下架
- [ ] 买家不能直接购买、议价或竞拍自己的闲置
- [ ] 直接购买和议价同意后生成的订单先进入待付款，支付后才进入待发货
- [ ] 卖家拒绝议价不会生成订单，议价状态可追踪
- [ ] 同一商品不能同时存在多个进行中拍卖，历史拍卖不阻塞再次发起
- [ ] 竞拍出价满足最低加价幅度，关闭或流拍后不能继续出价
- [ ] 二手订单发货、物流、确认收货和待评价状态闭环正确
- [ ] 前端 mock 与后端接口路径一致，尤其是 `/category/tree?scene=SECONDHAND`
- [ ] 自动化测试和 UI 截图证据可复现
- [ ] k6 压测框架可复用到单体和微服务版本，数据重置方案清楚

## 现场演示步骤和取证点

1. 展示 Issue、分支和 PR 页面，截取任务编号、负责人、提交和评审状态。
2. 执行后端测试命令：`cd backend && mvn -B "-Dtest=SecondhandProductServiceImplTest,SecondhandTradeServiceImplTest,SecondhandOrderFlowIntegrationTest,SecondhandAuctionIntegrationTest" test`。
3. 打开 Swagger 或 `04_tests/UC16-UC20-demo.http`，展示 UC16-UC20 相关接口。
4. 演示 UC16 发布闲置和我的闲置管理；说明分类树 mock 缺口已修复，并保留旧截图作为问题发现证据。
5. 演示 UC17 二手直接购买：详情页、确认地址、支付弹窗、支付后待发货订单。
6. 演示 UC18 议价：买家发起、卖家处理、同意后买家出现待付款订单。
7. 演示 UC19 拍卖：卖家发起、买家出价、卖家工作台查看当前价和领先买家。
8. 演示 UC20 履约：卖家发货、买家待收货、确认收货后待评价。
9. 展示 `04_tests/performance/k6/` 和 `04_tests/UC16-UC20-k6压测框架与数据重置方案.md`，说明商品搜索、新品下单、二手拍卖出价/购买三类性能对象。
10. 回填截图链接、测试报告链接和任何未关闭 Issue。
