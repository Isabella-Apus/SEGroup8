# REQ08 / UC08 店铺查看、设置和装修

## 业务目标

访客可以查看开放店铺及其在售商品摘要；卖家可以查看、设置和装修本人店铺。关闭店铺不得公开访问，商品目录不可用时店铺主体仍应降级展示。

## 参与者与前置条件

- 参与者：访客、已认证卖家。
- 协作者：店铺服务、商品目录服务。
- 前置条件：店铺已创建；卖家身份由受信网关通过 `X-Seller-Id` 传递。

## 主成功场景

1. 访客访问开放店铺，获得店铺主体、装修和在售商品摘要。
2. 卖家查询本人店铺。
3. 卖家修改店铺名称、公告和营业状态。
4. 卖家选择允许的装修模板并保存 JSON 对象形式的装修内容。

## 异常与降级场景

- `CLOSED` 店铺公开访问时返回 `SHOP_NOT_FOUND`。
- 不存在或不属于当前卖家的店铺不可查看、设置或装修。
- 商品目录不可用时返回店铺主体、空商品列表和 `catalogAvailable=false`。
- 模板只允许 `CLASSIC`、`GRID`、`STORY`。
- 装修内容必须是合法 JSON 对象且不得超过 20000 字符。

## 验收条件

- AC08-01：开放店铺可查看，设置和装修能够持久化，目录故障可降级。
- AC08-02：不允许的装修模板被拒绝。
- AC08-03：关闭店铺不可公开访问，卖家数据相互隔离。
- AC08-04：非法、非对象和超长装修内容被拒绝。
- AC08-05：需求、设计、代码、测试和原始证据可以双向追溯。
