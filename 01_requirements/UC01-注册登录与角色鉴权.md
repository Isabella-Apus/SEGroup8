# REQ01 / UC01 注册、登录与角色鉴权

## 业务目标

允许游客注册、已注册用户登录，并通过 JWT 和用户角色保护后台管理接口。

## 参与者、前置条件与触发

- 参与者：游客、普通用户、官方卖家、管理员。
- 前置条件：后端和 `user` 表可用；登录用户具有有效账号状态。
- 触发：用户提交注册/登录表单，或访问需要身份认证的后台接口。

## 接口与成功结果

| 方法 | 路径 | 结果 |
|---|---|---|
| POST | `/api/auth/register` | 创建 `USER`、`NORMAL` 用户，密码以加密形式保存 |
| POST | `/api/auth/login` | 返回 JWT、角色和用户摘要 |
| 受保护 API | `Authorization: Bearer <JWT>` | JWT 可被拦截器解析并写入当前用户上下文 |

## 主成功流

1. 游客提交用户名、密码、昵称和可选联系方式。
2. 系统校验必填字段、密码长度和联系方式格式。
3. 系统检查用户名未占用，以加密形式写入 `user` 表。
4. 用户提交正确账号密码。
5. 系统校验账号状态，签发包含用户 ID、用户名和角色的 JWT。
6. 用户携带 JWT 访问业务接口；管理员携带 ADMIN 账号访问后台管理接口。

## 备选与异常流

- 用户名重复：返回业务错误，不新增用户。
- 必填字段、密码长度或手机号格式不合法：返回 `code=400`，不调用注册服务。
- 用户不存在或密码错误：返回 `code=401`，不签发 JWT。
- 用户状态不是 `NORMAL`：拒绝登录。
- JWT 缺失、篡改或过期：返回 `code=401`。
- USER/SELLER 调用 ADMIN 接口：返回 `code=403`。

## 可验证结果

- AC01-01：注册成功后 `user.role=USER`、`user.status=NORMAL`，数据库不保存明文密码。
- AC01-02：登录成功响应包含非空 `data.token`、角色和用户摘要。
- AC01-03：重复注册、错误密码和非法参数均返回明确的失败响应。
- AC01-04：普通用户不能访问管理员接口，管理员可以访问。
- AC01-05：需求、组件、代码、测试可由 `REQ01/UC01` 追溯到 `UNIT01/INT01`。
