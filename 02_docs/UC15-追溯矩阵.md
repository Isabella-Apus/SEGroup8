# UC15 订单评价、追评与回复追溯矩阵

| 需求与验收条件 | 设计组件 | API 与页面 | 数据表 | 自动化证据与缺口 |
|---|---|---|---|---|
| `REQ15 / AC15-01`：本人待评价订单首评并原子完成 | `OrderController#review`、`OrderServiceImpl#submitMyOrderReview`、`ReviewMapper` | `POST /api/order/{id}/review`；订单详情 | `review`、`order_info` | 当前无直接自动化证据；待补 `UT-UC15-001`、`API-UC15-001/004` |
| `REQ15 / AC15-02`：逐商品评价仅覆盖订单内商品 | `reviewItems`、订单/商品归属 Mapper | `POST /api/order/{id}/review/items` | `review`、`order_item` | 待补 `UT-UC15-002/003`、`API-UC15-003` |
| `REQ15 / AC15-03`：最多一次追评且仅商品所有者可回复 | `ReviewController#followup/#reply`、`ReviewMapper` | 追评/回复接口；买家/商家评价页 | `review`、`product`、`shop`、`secondhand_product` | 待补 `UT-UC15-004/005`、`API-UC15-002/003` |
| `REQ15 / AC15-04`：买家和卖家查询与数据一致 | `ReviewController` 查询方法 | `GET /api/review/my`、`GET /api/review/seller/list` | `review` 及商品归属表 | 待补 `API-UC15-005` 和买卖双方 E2E |
