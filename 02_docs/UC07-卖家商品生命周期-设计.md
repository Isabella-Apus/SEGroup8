# UC07 卖家商品生命周期设计

## 接口设计

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/catalog/seller/products` | 查询当前卖家的商品 |
| POST | `/api/catalog/seller/products` | 创建 `DRAFT` 商品 |
| PUT | `/api/catalog/seller/products/{id}` | 编辑允许状态下的本人商品 |
| POST | `/api/catalog/seller/products/{id}/actions/{action}` | 执行 `SUBMIT`、`OFF_SHELF`、`ARCHIVE` |
| POST | `/api/catalog/internal/products/{id}/risk-decision` | 应用审核通过或驳回结果 |

卖家接口通过 `X-Seller-Id` 接收网关传递的受信身份。生产环境必须阻止公网直接访问内部审核决定接口。

## 状态模型

```mermaid
stateDiagram-v2
  [*] --> DRAFT: 创建商品
  DRAFT --> PENDING_REVIEW: SUBMIT
  DRAFT --> ARCHIVED: ARCHIVE
  PENDING_REVIEW --> ON_SALE: 审核通过
  PENDING_REVIEW --> REJECTED: 审核驳回
  REJECTED --> PENDING_REVIEW: 修改后 SUBMIT
  REJECTED --> ARCHIVED: ARCHIVE
  ON_SALE --> OFF_SHELF: OFF_SHELF
  OFF_SHELF --> PENDING_REVIEW: SUBMIT
  OFF_SHELF --> ARCHIVED: ARCHIVE
```

## 组件交互

```mermaid
sequenceDiagram
  actor Seller as 卖家
  participant API as CatalogController
  participant Svc as CatalogService
  participant DB as catalog_schema
  participant Risk as risk-service
  Seller->>API: 创建/编辑/执行生命周期动作
  API->>Svc: sellerId + command
  Svc->>DB: 校验归属和当前状态
  alt 合法操作
    Svc->>DB: 保存商品和新状态
    opt SUBMIT
      Svc->>Risk: 创建审核单
      alt 风控不可用
        Svc->>DB: 写 integration_outbox
      end
    end
    Svc-->>Seller: 返回商品
  else 越权或非法转换
    Svc-->>Seller: 稳定领域错误码
  end
```

## 核心对象与规则

- `CatalogController`：卖家 HTTP 接口、参数校验和身份头解析。
- `CatalogService`：商品归属校验、创建、编辑、状态持久化和 Outbox 降级。
- `LifecyclePolicy`：集中定义允许的状态转换。
- `ProductCommand`：创建和编辑商品的命令对象。
- `integration_outbox`：风控调用失败时保存待重试事件。
