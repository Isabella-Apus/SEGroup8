# UC12 订单支付与取消追溯矩阵

| 需求与验收条件 | 设计组件 | API 与页面 | 数据表 | 自动化证据与缺口 |
|---|---|---|---|---|
| `REQ12 / AC12-01`：本人待付款订单只能支付一次 | `OrderController#pay`、`OrderServiceImpl#payMyOrder`、`OrderStateMachine` | `POST /api/order/{id}/pay`；订单列表/详情 | `order_info`、`balance`、`transaction_record` | `payMyOrder_shouldSplitCartItemsIntoIndependentPaidOrders` 覆盖主路径；待补状态机、余额不足和重复支付测试 |
| `REQ12 / AC12-02`：拆分订单金额与优惠承担额守恒 | `splitPaidOrderByItem`、`VoucherService` | 支付响应 | `order_info`、`order_item`、`user_voucher` | 已有拆分主路径；待补 `API-UC12-001` 跨表断言 |
| `REQ12 / AC12-03`：未支付取消回补库存并释放优惠券 | `OrderController#cancel`、`cancelMyOrder`、`restoreStockForNewItems` | `POST /api/order/{id}/cancel` | `product`、`user_voucher`、`order_info` | `cancelMyOrder_shouldRestoreStockWhenUnpaidEvenIfOrderStatusNotPendingPay`；待补 `API-UC12-002` |
| `REQ12 / AC12-04`：非法状态、越权和重复请求无二次副作用 | `OrderStateMachine`、幂等与版本控制 | 支付/取消接口 | `order_info.version`、`idempotency_record` | 待补 `UT-UC12-001/002`、`API-UC12-003/004` 和 E2E |
