# UC11 购物车结算与创建订单追溯矩阵

| 需求与验收条件 | 设计组件 | API 与页面 | 数据表 | 自动化证据与缺口 |
|---|---|---|---|---|
| `REQ11 / AC11-01`：合法结算生成唯一待付款订单，金额由服务端计算 | `OrderController#create`、`OrderServiceImpl#createOrder` | `POST /api/order/create`；`CartView.vue`、`ProductDetailView.vue` | `order_info`、`order_item`、`product` | 待补 `UT-UC11-001/002`、`API-UC11-001` |
| `REQ11 / AC11-02`：库存、订单和优惠券事务一致 | `OrderServiceImpl`、`VoucherService#occupyForOrder` | 创建订单失败响应 | `product`、`order_info`、`order_item`、`user_voucher` | 待补 `API-UC11-002` 事务回滚测试 |
| `REQ11 / AC11-03`：库存、地址、权限、优惠券和重复请求均可验证 | `JwtAuthInterceptor`、`IdempotencyInterceptor`、各实体 Mapper | `POST /api/order/create` | `address`、`user_block`、`idempotency_record` | `IdempotencyInterceptorTest` 仅覆盖通用幂等；待补 `UT-UC11-003/004`、`API-UC11-003` |
| `REQ11 / AC11-04`：页面、接口、数据库和日志交叉验证 | 前端结算页、订单域、链路日志 | 创建后跳转订单详情 | 上述全部 | 待补 `E2E-UC11-001` |
