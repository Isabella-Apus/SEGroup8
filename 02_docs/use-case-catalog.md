## 每个用例的统一验收门

只有同时满足以下条件，单个用例才能标记 `Done`：

- 主流程至少成功执行一次。
- 至少一个异常或权限分支有明确结果。
- 有真实测试账号、测试数据和实际执行时间。
- 有接口/API、页面、日志或数据库中的可验证证据。
- 负责人提交测试结果，评审人完成评审。
- 需求编号、用例编号、代码位置、测试编号和结果可以互相追溯。
- 失败项应记录负责人、计划完成日期和阻塞原因，完成修复与复验后再关闭。
