# UC14 订单售后退款追溯矩阵

| 需求与验收条件 | 设计/实现 | API 与数据表 | 自动化证据 | 状态 |
|---|---|---|---|---|
| 买家申请、卖家拒绝、拒绝后再申请 | `OrderController`、`OrderServiceImpl` | `POST /api/order/{id}/refund`；`order_info`、`order_after_sale_log` | `buyerApply_sellerReject_reapply_adminApprove_recordsCompleteOrderedAuditLog` | MySQL PASS |
| 卖家同意/拒绝、管理员同意/拒绝 | `OrderServiceImpl`、`AdminOrderController` | 卖家及管理员退款决策 API | 主流程、`adminReject_recordsDecisionWithoutRefundSideEffects` | MySQL PASS |
| 仅退款与退货退款边界 | `validateRefundMode`、退款状态机 | `refund_mode`、`logistics_status`、`after_sales_deadline` | `refundModes_enforceOnlyRefundAndReturnRefundBoundaries_withoutMutatingRejectedRequests` | MySQL PASS |
| 买家、卖家、管理员权限隔离 | `AccessControl`、JWT 拦截器 | 买家申请、卖家处理、管理员处理 API | `buyerSellerAndAdminPermissions_rejectUnrelatedActors_andLeaveStateUnchanged` | MySQL/HTTP PASS |
| 已结算退款资金守恒 | `EscrowSettlementService`、`refundMoneyToBuyer` | `balance`、`transaction_record` | `settledRefund_returnsBuyerFunds_debitsSeller_andKeepsRefundLedgerConserved` | MySQL PASS |
| 库存按退款模式处理 | `restoreStockForNewItems` | `product.stock` | 待发货仅退款回补；退货退款库存保持不变 | MySQL PASS |
| 并发审核最多一次副作用 | 乐观锁版本条件 | `order_info.version`、退款流水、售后日志 | `concurrentSellerAndAdminApproval_producesExactlyOneRefundAndOneApprovalLog` | MySQL PASS |
| 待发货仅退款自动通过 | 系统决策分支 | 订单、余额、库存、日志 | `pendingShipOnlyRefund_autoApproves_refundsBuyer_andRestoresStock` | MySQL PASS |
| 日志记录处理人、来源、理由并有序 | `OrderAfterSaleLogMapper` | `order_after_sale_log` | 四阶段日志逐字段断言 | MySQL PASS |
| 浏览器真实售后闭环 | `frontend/e2e/domain-c/uc14-after-sale.spec.ts` | 买家、卖家、管理员页面与 API | `04_tests/UC14/evidence/raw-reports/playwright/` | 已有 Evidence；目标提交待 CI 复验 |
