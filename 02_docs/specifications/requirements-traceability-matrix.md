```mermaid
  UC --> DESIGN[DESIGN-CLASSxx 详细类图]
  UC --> OBJ[OBJ-SEQxx 对象顺序]
  OBJ --> CODE[页面/Controller/Service/Mapper]

  CODE --> E2E[E2E-TCxx 业务链路测试]
  UNIT --> RESULT[结果与原始证据]
  MVC --> RESULT
  INT --> RESULT
  E2E --> RESULT
```
