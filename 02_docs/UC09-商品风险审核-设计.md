# UC09 商品风险审核设计

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | `/internal/risk-audits` | 创建审核单并执行风险词规则 |
| GET | `/api/admin/risk-audits` | 管理员按状态查询审核单 |
| POST | `/api/admin/risk-audits/{id}/decision` | 管理员通过或驳回审核单 |

`RiskRule` 规范化文本并匹配禁用词；`RiskService` 负责状态机和持久化；`risk_audits` 保存商品快照、风险级别与决定。目录回调异常时写入 `integration_outbox` 供可靠补偿。

审核单只允许 `PENDING -> APPROVED/REJECTED`。驳回必须带原因，终态再次决定返回 `ALREADY_DECIDED`。管理端身份由受信网关以 `X-Admin-Id` 传递。服务可用 `mvn -f microservices/risk-service/pom.xml clean test` 独立验证。
