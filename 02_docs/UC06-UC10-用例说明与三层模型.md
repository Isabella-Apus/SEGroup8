# UC06-UC10 用例说明与三层模型

## UC06 商品搜索筛选与详情

| 项目 | 内容 |
|---|---|
| 参与者 | 访客、已登录买家 |
| 触发条件 | 用户输入关键词或打开商品列表 |
| 前置条件 | 商品目录服务可访问；至少存在一个在售商品 |
| 主成功流程 | 输入关键词与筛选条件；系统返回匹配商品；用户选择商品；系统返回在售商品详情 |
| 备选/异常流程 | 无结果时返回空列表；筛选参数非法时返回 400；商品已下架时详情返回不存在 |
| 可验证结果 | 结果仅含 `ON_SALE` 商品，且分类、价格区间、排序条件正确 |

### UC06 系统级图

```mermaid
sequenceDiagram
  actor Buyer as 买家
  participant System as 交易平台
  Buyer->>System: 输入关键词、分类、价格与排序
  System-->>Buyer: 返回匹配的在售商品
  Buyer->>System: 选择商品
  System-->>Buyer: 返回商品详情或已下架提示
```

### UC06 组件级图

```mermaid
sequenceDiagram
  participant UI as 商品列表/详情页
  participant API as CatalogController
  participant Svc as CatalogService
  participant DB as catalog_schema
  UI->>API: GET /api/catalog/products
  API->>Svc: search(filters)
  Svc->>DB: 查询 ON_SALE 商品
  DB-->>Svc: 商品集合
  Svc-->>UI: 过滤、排序后的商品
  UI->>API: GET /api/catalog/products/{id}
  API->>DB: 查询在售商品详情
  DB-->>UI: 商品详情/不存在
```

### UC06 对象级图

```mermaid
sequenceDiagram
  participant C as CatalogController
  participant S as CatalogService
  participant J as JdbcClient
  participant P as Product
  C->>S: search(keyword, category, shopId, min, max, sort)
  S->>J: sql(ON_SALE).query(Product.class)
  J-->>S: List<Product>
  loop 每个 Product
    S->>P: 检查关键词/分类/价格
  end
  S-->>C: sorted List<Product>
```

## UC07 卖家商品生命周期

| 项目 | 内容 |
|---|---|
| 参与者 | 卖家；商品风控系统 |
| 触发条件 | 卖家新增、编辑、提交审核、下架或归档商品 |
| 前置条件 | 卖家身份有效且只能操作自己的商品 |
| 主成功流程 | 新建草稿；编辑；提交审核；审核通过后上架；卖家下架或归档 |
| 备选/异常流程 | 非法状态转换被拒绝；风控服务不可用时商品保持待审核并写入 Outbox；审核驳回后可修改重提 |
| 可验证结果 | 状态只按既定状态机变化，越权操作失败，跨服务失败事件可重试 |

### UC07 系统级图

```mermaid
sequenceDiagram
  actor Seller as 卖家
  participant System as 交易平台
  participant Risk as 风控系统
  Seller->>System: 新建并编辑商品草稿
  Seller->>System: 提交审核
  System->>Risk: 请求商品风险审核
  alt 审核通过
    Risk-->>System: APPROVED
    System-->>Seller: 商品已上架
  else 审核驳回
    Risk-->>System: REJECTED
    System-->>Seller: 展示驳回结果，可修改重提
  else 风控不可用
    System-->>Seller: 已受理，等待审核
  end
```

### UC07 组件级图

```mermaid
sequenceDiagram
  participant UI as 卖家工作台
  participant API as CatalogController
  participant Svc as CatalogService
  participant DB as catalog_schema
  participant Risk as risk-service
  UI->>API: POST /seller/products
  API->>Svc: create()
  Svc->>DB: 保存 DRAFT
  UI->>API: POST /actions/SUBMIT
  API->>Svc: transition(SUBMIT)
  Svc->>DB: 更新 PENDING_REVIEW
  Svc->>Risk: POST /internal/risk-audits
  alt 调用失败
    Svc->>DB: 写 integration_outbox
  end
```

### UC07 对象级图

```mermaid
sequenceDiagram
  participant C as CatalogController
  participant S as CatalogService
  participant L as LifecyclePolicy
  participant P as Product
  participant R as RestClient
  participant O as integration_outbox
  C->>S: transition(sellerId,id,SUBMIT)
  S->>P: owned(id,sellerId)
  S->>L: next(P.status,SUBMIT)
  L-->>S: PENDING_REVIEW
  S->>R: requestRiskAudit(P)
  alt RuntimeException
    S->>O: insert(PENDING event)
  end
  S-->>C: updated Product
```

## UC08 店铺查看、设置和装修

| 项目 | 内容 |
|---|---|
| 参与者 | 访客、卖家 |
| 触发条件 | 访客查看店铺；卖家修改店铺信息或装修 |
| 前置条件 | 店铺存在；卖家只能维护本人店铺 |
| 主成功流程 | 访客查看公开店铺和商品；卖家设置名称、公告、营业状态；选择模板并保存 JSON 装修内容 |
| 备选/异常流程 | 店铺关闭时不可公开查看；商品目录不可用时仍返回店铺主体并标注降级；非法模板或装修内容被拒绝 |
| 可验证结果 | 店铺设置持久化；公开页反映最新配置；目录故障不会拖垮店铺服务 |

### UC08 系统级图

```mermaid
sequenceDiagram
  actor Visitor as 访客
  actor Seller as 卖家
  participant System as 交易平台
  Seller->>System: 修改名称、公告和营业状态
  Seller->>System: 选择模板并发布装修
  System-->>Seller: 保存成功
  Visitor->>System: 查看公开店铺
  System-->>Visitor: 店铺信息、装修和商品/降级提示
```

### UC08 组件级图

```mermaid
sequenceDiagram
  participant UI as 店铺页面
  participant API as ShopController
  participant Svc as ShopService
  participant DB as shop_schema
  participant Catalog as catalog-service
  UI->>API: GET /api/shops/{id}
  API->>Svc: publicView(id)
  Svc->>DB: 查询 OPEN 店铺
  Svc->>Catalog: GET /api/catalog/products?shopId=id
  alt 目录服务不可用
    Svc-->>UI: 店铺 + 空商品 + catalogAvailable=false
  else 正常
    Svc-->>UI: 店铺 + 商品
  end
```

### UC08 对象级图

```mermaid
sequenceDiagram
  participant C as ShopController
  participant S as ShopService
  participant D as DecorationPolicy
  participant J as JdbcClient
  participant Shop as Shop
  C->>S: decorate(sellerId, command)
  S->>D: validate(template, contentJson)
  D-->>S: valid
  S->>J: update shops
  S->>J: select by sellerId
  J-->>S: Shop
  S-->>C: Shop
```

## UC09 商品风险审核

| 项目 | 内容 |
|---|---|
| 参与者 | 风控管理员；商品目录服务 |
| 触发条件 | 商品提交审核 |
| 前置条件 | 商品处于待审核状态；快照包含名称与描述 |
| 主成功流程 | 规则扫描并生成审核单；管理员查看待审列表；通过或填写原因驳回；结果回传商品目录 |
| 备选/异常流程 | 重复决定被拒绝；驳回未填原因被拒绝；回调目录失败时写 Outbox 等待重试 |
| 可验证结果 | 审核单记录风险等级、命中词、管理员、决定和时间，商品最终状态一致 |

### UC09 系统级图

```mermaid
sequenceDiagram
  participant Catalog as 商品系统
  participant Risk as 风控系统
  actor Admin as 风控管理员
  Catalog->>Risk: 提交商品审核快照
  Risk-->>Catalog: 已生成待审单
  Admin->>Risk: 查看待审核商品
  Risk-->>Admin: 风险等级和命中规则
  Admin->>Risk: 通过/驳回并填写原因
  Risk->>Catalog: 回传审核决定
```

### UC09 组件级图

```mermaid
sequenceDiagram
  participant Catalog as catalog-service
  participant API as RiskController
  participant Svc as RiskService
  participant DB as risk_schema
  participant Callback as Catalog callback API
  Catalog->>API: POST /internal/risk-audits
  API->>Svc: create(snapshot)
  Svc->>DB: 保存 PENDING 审核单
  API->>Svc: decide(auditId,adminId)
  Svc->>DB: 更新 APPROVED/REJECTED
  Svc->>Callback: POST risk-decision
  alt 回调失败
    Svc->>DB: 写 integration_outbox
  end
```

### UC09 对象级图

```mermaid
sequenceDiagram
  participant C as RiskController
  participant S as RiskService
  participant R as RiskRule
  participant A as Audit
  participant RC as RestClient
  C->>S: create(CreateCommand)
  S->>R: evaluate(name + description)
  R-->>S: RuleResult(level,hits)
  S-->>C: Audit(PENDING)
  C->>S: decide(id,admin,DecisionCommand)
  S->>A: 检查 PENDING 与驳回原因
  S->>RC: callback(productId,approved)
```

## UC10 浏览记录、搜索历史和热词

| 项目 | 内容 |
|---|---|
| 参与者 | 已登录买家；访客（查看热词） |
| 触发条件 | 用户浏览商品、执行搜索、查看或删除历史 |
| 前置条件 | 记录个人历史时具有用户标识 |
| 主成功流程 | 记录/合并浏览行为；记录并规范化搜索词；查询个人历史；聚合并返回热词；删除或清空浏览记录 |
| 备选/异常流程 | 空白或超长关键词被拒绝；用户不能删除他人的记录；重复浏览移动到最新位置 |
| 可验证结果 | 个人历史按时间倒序；热词按次数排序；删除操作限定当前用户 |

### UC10 系统级图

```mermaid
sequenceDiagram
  actor Buyer as 买家
  participant System as 交易平台
  Buyer->>System: 浏览商品
  System-->>Buyer: 记录成功
  Buyer->>System: 搜索关键词
  System-->>Buyer: 保存规范化搜索词并累计热度
  Buyer->>System: 查看个人历史与热词
  System-->>Buyer: 返回时间倒序历史和热词榜
  Buyer->>System: 删除指定浏览记录
  System-->>Buyer: 删除成功/无权删除
```

### UC10 组件级图

```mermaid
sequenceDiagram
  participant UI as 浏览/搜索页面
  participant API as BehaviorController
  participant Svc as BehaviorService
  participant DB as behavior_schema
  UI->>API: POST /browse-history
  API->>Svc: recordBrowse(userId,product)
  Svc->>DB: 去重并写入最新记录
  UI->>API: POST /search-history
  API->>Svc: recordSearch(userId,keyword)
  Svc->>DB: 写搜索历史并累加 keyword_stats
  UI->>API: GET /hot-keywords
  DB-->>UI: Top 10 热词
```

### UC10 对象级图

```mermaid
sequenceDiagram
  participant C as BehaviorController
  participant S as BehaviorService
  participant K as KeywordPolicy
  participant J as JdbcClient
  participant H as HotKeyword
  C->>S: recordSearch(userId,raw)
  S->>K: normalize(raw)
  K-->>S: normalized keyword
  S->>J: insert search_history
  S->>J: select/update keyword_stats
  C->>S: hot()
  S->>J: Top 10 query
  J-->>S: List<HotKeyword>
  S-->>C: List<HotKeyword>
```
