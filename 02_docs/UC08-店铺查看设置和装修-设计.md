# UC08 店铺查看、设置和装修设计

## 接口设计

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/shops/{id}` | 获取开放店铺、装修及商品摘要 |
| GET | `/api/shops/seller/current` | 查询当前卖家店铺 |
| PUT | `/api/shops/seller/current/settings` | 修改名称、公告和营业状态 |
| PUT | `/api/shops/seller/current/decoration` | 保存装修模板和 JSON 内容 |

卖家接口使用 `X-Seller-Id` 接收网关传递的受信身份。`shops` 表由 `shop-service` 独占写入。

## 组件交互

```mermaid
sequenceDiagram
  actor Visitor as 访客
  actor Seller as 卖家
  participant API as ShopController
  participant Svc as ShopService
  participant DB as shops
  participant Catalog as catalog-service
  Visitor->>API: GET /api/shops/{id}
  API->>Svc: publicView(id)
  Svc->>DB: 查询 OPEN 店铺
  Svc->>Catalog: 查询店铺在售商品
  alt Catalog 可用
    Catalog-->>Svc: 商品摘要
  else Catalog 不可用
    Svc->>Svc: products=[]; catalogAvailable=false
  end
  Svc-->>Visitor: 店铺视图
  Seller->>API: 设置或装修本人店铺
  API->>Svc: sellerId + command
  Svc->>DB: 按 seller_id 更新并回读
  Svc-->>Seller: 更新后的店铺
```

## 核心对象与规则

- `ShopController`：公开及卖家接口、参数校验、身份头解析。
- `ShopService.publicView`：仅查询开放店铺并调用商品目录，失败时降级。
- `ShopService.settings`：按卖家身份更新名称、公告和营业状态。
- `ShopService.decorate`：校验装修规则后按卖家身份保存。
- `DecorationPolicy`：模板白名单、JSON 对象格式和长度校验。
- `ShopView`：店铺主体、商品摘要和目录可用状态。
