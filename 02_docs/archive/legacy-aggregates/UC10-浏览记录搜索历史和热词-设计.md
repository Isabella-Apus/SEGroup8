# UC10 浏览记录、搜索历史和热词设计

| 方法 | 路径 | 作用 |
|---|---|---|
| POST/GET/DELETE | `/api/behavior/browse-history` | 记录、查询、清空本人浏览历史 |
| DELETE | `/api/behavior/browse-history/{id}` | 删除本人单条浏览历史 |
| POST/GET | `/api/behavior/search-history` | 记录、查询本人搜索历史 |
| GET | `/api/behavior/hot-keywords` | 获取 Top 10 热词 |

`BehaviorService` 以 `user_id` 约束个人数据。浏览写入前删除相同三元组后重建，实现去重和刷新时间；查询按时间倒序。`KeywordPolicy` 负责搜索词规范化，`keyword_stats` 在事务内累计并按次数降序、关键词升序返回前 10。身份由受信网关以 `X-User-Id` 传递。

服务可通过 `mvn -f microservices/behavior-service/pom.xml clean test` 独立验证，也可由 Dockerfile 构建容器镜像。
