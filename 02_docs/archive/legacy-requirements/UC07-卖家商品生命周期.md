# UC07 卖家商品生命周期

- 需求编号：`REQ07`
- 用例编号：`UC07`
- 所属领域：Domain B（Catalog and Shop）

## 业务目标

卖家在自己的店铺内创建、编辑、查询、上下架、删除商品并调整库存；平台必须按当前登录卖家和店铺校验所有权，防止买家或其他卖家越权操作。

## 参与者与前置条件

- 卖家已登录并拥有有效店铺；管理员可按现有平台权限执行管理操作。
- 商品名称、价格、库存、分类和上下架状态满足后端校验规则。
- 买家只能访问公开且在售的商品信息，不能进入卖家商品工作台。

## 主成功场景

1. 卖家进入“我的商品”，系统按当前卖家店铺分页查询商品。
2. 卖家提交商品名称、封面、描述、价格、库存、分类及状态，系统校验分类归属和字段边界。
3. 系统将商品绑定到当前卖家店铺并持久化，返回商品详情。
4. 卖家编辑商品资料，或通过库存调整接口增加/减少库存。
5. 卖家切换上架/下架状态；下架或删除后，公开查询不再把商品作为可购买商品返回。

## 备选与异常流程

- 价格区间非法、必填字段缺失或分类层级不匹配：返回业务错误，不写入商品。
- 库存调整后结果小于零：拒绝操作，不更新库存。
- 商品不属于当前卖家店铺：返回未找到/无权操作结果，不泄露商品详情。
- 买家请求卖家接口：被认证/授权层拒绝。
- 查询公开商品时商品不在售：不返回可购买详情。

## 可验证结果与验收标准

| 编号 | 验收标准 |
| --- | --- |
| AC07-01 | 创建成功的商品绑定当前卖家店铺，名称去除首尾空白并可再次查询。 |
| AC07-02 | 卖家分页列表只返回本人店铺商品；其他卖家不能编辑、删除、上下架或调库存。 |
| AC07-03 | 编辑、状态切换和库存调整后的值可从接口重新读取；库存不得变为负数。 |
| AC07-04 | 非法价格区间、分类关系或库存结果被拒绝，失败操作不产生持久化副作用。 |
| AC07-05 | 公开详情只暴露在售商品；买家不能访问卖家工作台接口。 |
