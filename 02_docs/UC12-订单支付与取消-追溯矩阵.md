# UC12 订单支付与取消追溯矩阵

| 需求与验收条件 | 设计组件 | API 与页面 | 数据表 | 自动化证据与缺口 |
|---|---|---|---|---|
| `REQ12 / AC12-01`：本人待付款订单只能支付一次 | `OrderController#pay`、`OrderServiceImpl#payMyOrder`、`OrderStateMachine` | `POST /api/order/{id}/pay`；订单列表/详情 | `order_info`、`balance`、`transaction_record` | Testcontainers MySQL 覆盖待付款成功、已支付/已完成拒绝、余额不足回滚和重复支付 |
| `REQ12 / AC12-02`：拆分订单金额与优惠承担额守恒 | `splitPaidOrderByItem`、`VoucherService` | 支付响应 | `order_info`、`order_item`、`user_voucher` | 多商品支付断言原价、卖家承担、平台承担、优惠和应付金额跨拆分订单守恒 |
| `REQ12 / AC12-03`：未支付取消回补库存并释放优惠券 | `OrderController#cancel`、`cancelMyOrder`、`restoreStockForNewItems` | `POST /api/order/{id}/cancel` | `product`、`user_voucher`、`order_info` | MySQL Integration 断言订单关闭、库存恢复和优惠券释放 |
| `REQ12 / AC12-04`：非法状态、越权和重复请求无二次副作用 | `OrderStateMachine`、幂等与版本控制 | 支付/取消接口 | `order_info.version`、`idempotency_record` | MySQL Integration 覆盖非买家、幂等重放及支付/取消竞态；Playwright 覆盖双成功链与刷新持久化 |
