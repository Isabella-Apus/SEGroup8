# UC13 订单发货、物流与收货追溯矩阵

| 需求与验收条件 | 设计组件 | API 与页面 | 数据表 | 自动化证据与缺口 |
|---|---|---|---|---|
| `REQ13 / AC13-01`：卖家发货并生成首条轨迹 | `OrderController#ship`、`OrderServiceImpl#shipSellerOrder`、`LogisticsServiceImpl` | `POST /api/order/{id}/ship`；商家订单页 | `order_info`、`logistics_trace` | 新品 MySQL Integration 断言待收货状态、首轨节点和状态说明 |
| `REQ13 / AC13-02`：轨迹有序可见且权限正确 | `LogisticsController`、`LogisticsEngine` | 物流推进/查询；订单时间线 | `logistics_path_template`、`logistics_trace` | 买家、实际卖家查询成功，无关用户返回 403 |
| `REQ13 / AC13-03`：人工/自动确认使用一致结算规则 | `confirmReceiveMyOrder`、`autoConfirmReceiveForSystem`、`EscrowSettlementService` | `POST /api/order/{id}/confirm-receive` | `order_info`、`balance`、`transaction_record` | MySQL 竞态断言订单版本只增加一次、卖家余额和流水只结算一次 |
| `REQ13 / AC13-04`：重复发货、终点和遗留合并订单结果可预测 | 订单状态、物流引擎和版本条件更新 | 发货/推进接口 | 订单与物流表 | 覆盖重复发货不重复首轨、遗留合并订单 409 且数据不变，并由 Playwright 验证双账号闭环 |
