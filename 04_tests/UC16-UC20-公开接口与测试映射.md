## 统一 API 验收规则

- 成功与业务失败均检查 `code`、`message` 和 `data`，不能只检查 HTTP 200。
- 修改类接口至少验证未登录、错误角色、非资源所有者和非法状态。
- 建单测试必须检查二手商品、订单主表、订单明细、价格和初始状态的一致性。
- 拍卖和议价测试必须覆盖重复处理，证明不会重复建单或覆盖终态。
- 每个组件与测试 PR 提供一条可复现 Maven 命令和明确的 Tests/Failures/Errors/Skipped 摘要。
