# UC14 Evidence

- `result-summary.json` records the Domain-C Maven run and exit status.
- `raw-reports/surefire/` contains the original JUnit XML and text reports.
- `raw-reports/playwright/` contains the original browser report, JSON/XML result and screenshot attachments.
- `screenshots/` contains the persisted after-sale page captured after administrator arbitration.
- `logs/` contains the runner log.

Evidence is generated by the commands documented in the UC14 test report; a passing summary is only published after those commands complete successfully.
