# Evidence index

- `playwright-final/`: final 5/5 compact JSON and JUnit XML reports.
- `playwright-uc18-rerun/`: targeted UC18 compact JSON and JUnit XML regression report.
- `playwright/`: initial 4/5 compact JSON and JUnit XML run retained as failure-to-fix evidence.
- `raw-reports/playwright-failure/`: initial UC18 failure context and one key screenshot.
- `raw-reports/surefire/`: Maven Surefire XML and text reports.
- `logs/`: local validation summary.

The generated JSON/XML reports retain their original execution-time artifact paths. Complete Playwright HTML, repeated success screenshots, traces and videos are generated by CI under `${{ runner.temp }}` and uploaded as short-lived GitHub Actions artifacts; they are intentionally excluded from Git to keep the repository reviewable. Only compact machine-readable evidence, summaries and a key failure screenshot remain versioned.
