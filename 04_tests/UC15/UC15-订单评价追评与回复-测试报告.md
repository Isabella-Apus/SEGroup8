# UC15 订单评价、追评与回复 API 测试计划

## 测试目标

验证订单级/逐商品首评、订单原子完成、一次追评、商品所有者回复和买卖双方查询隔离。

## 当前证据

- 当前没有直接覆盖首评、逐商品评价、追评、卖家回复或评价查询的自动化测试。
- `OrderServiceImplTest` 中声明 `ReviewMapper` mock 不等于已覆盖 UC15，本计划中的用例不得标记为已通过。

## 计划用例

| 编号 | 层级 | 场景 | 核心断言 |
|---|---|---|---|
| `UT-UC15-001` | 单元 | 订单级首评 | 全部商品写 ORIGINAL 且订单完成 |
| `UT-UC15-002/003` | 单元 | 逐商品评价与非法状态 | 只接受订单内商品且重复首评拒绝 |
| `UT-UC15-004` | 单元 | 追评 | 有首评时只允许一次 FOLLOWUP |
| `UT-UC15-005` | 单元 | 卖家回复 | 仅实际商品所有者可回复 |
| `API-UC15-001` | API | 买家首评 | 响应、review 记录和订单状态一致 |
| `API-UC15-002` | API | 回复后追评 | 查询结果形成完整评价对话 |
| `API-UC15-003` | API | 越权、重复和参数非法 | 明确业务码且数据库不变 |
| `API-UC15-004` | API | 多商品评价中途失败 | 全部回滚且订单仍待评价 |
| `API-UC15-005` | API | 买家/卖家筛选查询 | 分页正确且无跨卖家数据泄露 |
| `E2E-UC15-001/002` | E2E | 首评、回复和追评 | 买卖双方页面同步显示 |

## 验证命令

当前没有可代表 UC15 通过的 Maven 测试命令。实现计划用例后，至少应执行：

```powershell
cd backend
mvn '-Dtest=ReviewControllerWebMvcTest,ReviewServiceTest,ReviewFlowIntegrationTest' test
```

## 自动化执行结果

新增 `ReviewServiceTest`、`ReviewControllerWebMvcTest`、`ReviewFlowIntegrationTest`，全部标记 `DOMAIN_C` 与 `UC15`。定向执行共 6 个测试通过，覆盖订单级多商品首评、重复首评、非法商品批量回滚、卖家回复权限、追评前置条件及重复追评。

真实浏览器 `uc15-review.spec.ts` 已通过 1 个测试，覆盖买家首评、卖家回复、买家追评和刷新后持久化验证；原始报告和截图位于 `evidence/raw-reports/playwright/`。
